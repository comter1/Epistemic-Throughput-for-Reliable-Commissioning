============================================================
3. WHAT COUNTS AS AN UNSEEN TOPOLOGY
============================================================

A new random seed or node renumbering is NOT a new topology.

Training and held-out topology sets must differ structurally.

Examples include:

- different number and placement of queues;
- different placement/order of adapters;
- different branching and merging patterns;
- different legal component connections.

For the PRIMARY unseen-topology test:

keep component types, fault types, severity ranges, observation noise ranges, and task distribution comparable to training.

Change topology itself.

This is important because we want to isolate topology generalization.

The larger-topology test should additionally change graph size:

TRAIN:
    mainly 8-16 observable components

LARGER TEST:
    approximately 16-24 components

Do not mix all distribution shifts into the primary unseen-topology test.

============================================================
6. METHODS TO KEEP
============================================================

The main paper comparison should contain only the following core methods:

1. Fixed planned acquisition
   - chooses a complete acquisition plan using initial information;
   - cannot change later actions based on newly observed evidence.

2. Cost-aware myopic acquisition
   - strong one-step baseline;
   - explicitly considers information/diagnostic value and cost.

3. Short-horizon planner
   - approximately 1-2 step lookahead;
   - serves as a strong planning baseline.

4. Non-graph learned acquisition policy
   - comparable model size and training budget;
   - receives the same public system description and evidence;
   - do NOT intentionally remove topology information just to weaken it.

5. GNN learned acquisition policy
   - our main learned method.

6. Full recording
   - reference for maximum observation access and actual acquisition cost.

Remove redundant baseline variants from the mandatory main run.

Additional ablations can be run later if useful.

The GNN is expected to remain a small model.
Do not increase model size simply because two B200 GPUs are available.
