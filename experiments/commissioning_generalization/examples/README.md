# Contract examples, not main data

These JSON files test interfaces, not the simulator or scientific results. The graph is
an eight-component chain. Its illustrative private case is stored separately; it must
never be passed to a model. The example action cost uses two ports at50Hz for10s:
2*500*128 + 100*128 external bytes +160 calibration bytes =140,960.
The observation example shows just one record, not a complete execution. Final main
manifests are generated and sealed by the implemented CLI.
